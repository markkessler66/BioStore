BioStore

A local home for phylogenetic data. Open a file from the library, or drop files here to upload.

  • Networks (.nwk .newick .tree .trees .net) render as interactive diagrams. Multi-tree files include a summary of clade frequencies.
  • Alignments (.nex .fasta .phy) open in an editable grid with live statistics and format conversion.
  • Analyses runs PhyNetPy scoring and search against files in the store.
  • Jobs keeps every analysis you have run under this display name.
